
# TP3 - Programación Web Dinámica 

Aplicación desarrollada en Vue.js para la visualización de un catálogo de productos utilizando componentes, 
slots, componentes dinámicos, KeepAlive y hooks del ciclo de vida.

## Tecnologías utilizadas:

* Vue.js
* Vite
* JavaScript
* HTML
* CSS

## Pasos para ejecutar el proyecto:

### Paso 1. Abrir una terminal en la carpeta del proyecto

Ubicarse en la carpeta donde se encuentra el proyecto. 

### Paso 2. Instalar las dependencias

Ejecutar:

npm install

### Paso 3. Ejecutar la aplicación

Ejecutar:

npm run dev

### Paso 4. Abrir el navegador

Ingresar a la dirección indicada por Vite (por ejemplo: http://localhost:5173).
